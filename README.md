# MDS Aurad Syadziliyyah

Aplikasi Android fullscreen yang dibangun manual melalui GitHub Actions, tanpa Android Studio.

## Build
Setelah semua file di-upload ke repository GitHub, buka **Actions** → **Build MDS APK** → tunggu selesai → **Artifacts** → **MDS-APK**.

APK: `MDS_Aurad_Syadziliyyah_v1.0.apk`
